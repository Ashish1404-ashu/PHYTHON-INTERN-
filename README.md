# 🐍 Python ATM Console App

A console-based ATM application with multi-user authentication and persistent storage.

## 🚀 Features
- Multi-user login & signup
- Create / delete user
- Balance withdraw/deposit
- Persistent storage (JSON / text database)
- Transaction history with timestamps

## 🛠️ Tech Stack
- Python 3
- File handling (JSON)

## ▶ How to Run
1. Clone repo
2. Open terminal
3. Run:
   ```bash
   python atm_app.py
